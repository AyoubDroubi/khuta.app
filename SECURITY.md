# Security Policy

Khuta keeps all data on the device and does not request the Internet permission, so the usual remote attack surface is small. Still, a bug can expose private data (for example in backups, the app lock, or widgets and notifications).

## Reporting a vulnerability

Please report privately through GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting). Do not open a public issue for a security problem. Include the app version, Android version, steps to reproduce, and what an attacker could gain.

You can expect an acknowledgement within a few days and a fix or a clear answer as soon as it is understood. Credit is given unless you prefer to stay anonymous.

## Scope

In scope: the app and the tools in this repository. Out of scope: other apps, the Android platform itself, and unmodified third-party libraries (report those upstream).

## Supported versions

Only the latest release receives fixes.
